## Description

Information processing facilities should be implemented with redundancy sufficient to meet availability requirements.

## Evidence

(none — see Gaps)

## Gaps

Single-region deployment (West Europe); PostgreSQL Flexible Server does not have Zone Redundant HA configured. This is a known, previously identified open gap (also relevant to ISO 27001 A.5.30 and CRA availability requirements).
