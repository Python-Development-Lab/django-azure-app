## Description

Networks, systems and applications should be monitored for anomalous behaviour and appropriate actions taken to evaluate potential information security incidents.

## Evidence

Microsoft Sentinel with 3+ active analytics rules (zero-trust-device-verification, defender-active-scanning-nmap, HTTP Brute Force) plus Microsoft Defender Threat Intelligence feed for indicator enrichment.
