## Description

Rules for the secure development of software and systems should be established and applied.

## Evidence

A 7-job DevSecOps pipeline (Security Scan, IaC Scan, Tests & Lint, Check Infra, Terraform Apply, Deploy+Migrate, DAST ZAP) enforces security checks at multiple stages of every deployment.
